# 👑 Royal Birthday Surprise Website

A handcrafted, royal, gorgeous, interactive birthday surprise website designed for pure elegance, seamless storytelling, and delightful interactions.

---

## 🚀 How to Run Locally

You can open the website immediately without any server or build step:

```powershell
start index.html
```

Or simply **double-click `index.html`** in File Explorer! It opens directly in your browser.

---

## 🌐 How to Host on GitHub Pages (Instant & Free)

This project is built to run directly from the root folder without requiring any build step:

1. Create a GitHub repository and push this folder:
   ```bash
   git init
   git add .
   git commit -m "Royal Birthday Surprise"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```
2. On GitHub, go to your repository **Settings** → **Pages**.
3. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
4. Your website will be live in seconds at `https://YOUR_USERNAME.github.io/YOUR_REPO/`!

## ✨ Features & Polish

1. **Opening Ceremonial Countdown**:
   - Starts when the user opens the page.
   - Cinematic 5... 4... 3... 2... 1 countdown with golden light and chimes, smoothly dissolving into the celebration.
2. **Complete Manual Scroll Control**:
   - Full freedom to scroll back and forth naturally with your mouse wheel or finger touch.
   - No timers or automated scripts hijack your scrolling!
3. **Continuous Royal Canvas (No Boxy Panels)**:
   - Organic, seamless silk-ivory and champagne-gold canvas with floating gold dust particles and royal floral dividers.
4. **Interactive Diya-Lighting Ceremony**:
   - Traditional Indian brass diya on a lotus rangoli base.
   - Gently trace over the wick with your cursor or finger to light the progressive, flickering flame and warm halo.
5. **Interactive Cake-Cutting & Serving Ceremony**:
   - Drag across the cake to cut a slice, then tap to serve it gracefully onto a gold-rimmed porcelain plate with celebratory confetti!
6. **Five Memory Sections (Nine Personal Photographs)**:
   - Memory 1: *The Beginning* (Photos 1 & 2)
   - Memory 2: *Endless Laughter and Adventures* (Photos 3 & 4) with fine decorative Throwball court-line accents and corner ball ornament.
   - Memory 3: *Little Moments That Matter* (Photo 5) in a grand centerpiece frame.
   - Memory 4: *Moments to Treasure* (Photos 6 & 7) with fine decorative Badminton racket-string patterns and shuttlecock ornament.
   - Memory 5: *A Friendship to Treasure* (Photos 8 & 9).
7. **Final Grand Birthday Celebration**:
   - Centerpiece 10th photograph (`final-birthday-photo.jpg`) with floating 3D helium balloons, royal heartfelt message, and golden confetti burst!
8. **Audio System**:
   - Music is set to ON by default and begins on first interaction. Minimal header audio toggle with animated wavebars.
